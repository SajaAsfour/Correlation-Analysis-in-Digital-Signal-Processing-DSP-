# 🔊 Correlation Analysis in Digital Signal Processing (DSP)

## 📌 Overview
This repository contains my implementation of **Correlation Analysis** for the **ENCS4310: Digital Signal Processing** course at **Birzeit University**. The project focuses on understanding and implementing **cross-correlation and autocorrelation** to analyze signal similarity and determine the presence of one signal in another.

## 🛠 Features
- ✅ **Cross-Correlation & Autocorrelation** Computation
- ✅ **Comparison of Standard vs. Normalized Correlation**
- ✅ **Signal Similarity Analysis**
- ✅ **MATLAB Implementation & Visualization**
- ✅ **Practical Signal Analysis Using Sinusoids**

## 📂 Contents.
- 📄 **Report:** Discussion on the relation between convolution and correlation, results, and observations.

## 📌 Tasks Implemented
### **Task 1:** Relation Between Convolution & Correlation
- Discussed theoretical expression and use cases.
- Computed correlation for sample sequences.

### **Task 2:** Standard vs. Normalized Correlation
- Generated sinusoidal signals with different frequencies.
- Compared correlation methods to determine signal presence.
- Visualized results to assess which method is more effective.

## 📌 Requirements
- MATLAB
- Basic knowledge of signal processing concepts
